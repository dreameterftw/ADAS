# Andheri road extract

`andheri_osm_roads.json.gz` is a compact drivable-road extract for the Andheri,
Mumbai showcase area. It was obtained from OpenStreetMap on 2026-10-23 and
contains road-node coordinates and directed edges with estimated travel times.

© OpenStreetMap contributors. OpenStreetMap data is available under the Open
Database License (ODbL). See https://www.openstreetmap.org/copyright.

The extract keeps the showcase reproducible when the hosting service cannot
reach OpenStreetMap at startup. Its road geometry can become outdated; traffic
conditions, closures, and provider feeds are not live in this bundled extract.
